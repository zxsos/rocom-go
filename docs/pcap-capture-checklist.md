## 二、还缺，值得专门录的（按优先级）

### 1. 对手的技能参数 ⭐ 最高优先
对手技能大多拿不到 —— 只有**他施放技能那一刻**才会下发 `damage_param_result`。
- 怎么录：一场**势均力敌、打满 10 回合以上**，别一回合秒了；让对手多换宠、多放技能。

### 2. 连击段数
`cast_cnt` 实测大多是 1，段数拿不准，需要定位真实段数字段。
- 怎么录：用技能描述里带「N连击」的技能（如「3连击」「2连击」）打一场。

### 3. 天气局
已有天气相关 buff（如「冬至」改暴风雪），但天气的伤害规则还没接。
- 怎么录：用改天气技能打一场（暴风雪/雨天…）。

### 4. 负面状态（roco 的 `negative-status.js` 共 5 种）
灼烧 / 冻结 / 寄生 / 中毒 / 引电。目前只见过冻结、中毒。
- 怎么录：火系（灼烧）、草系（寄生）、电系（引电）技能各打一次，最好同一场出现。

### 5. 更多印记
已认：`冻结` `中毒` `减速` `风起` `湿润` `光合` `棘刺`。
还缺：**星陨、蓄势、攻击、萌芽、重组、龙噬、降灵、暗涌**。
- 怎么录：用技能描述里带「获得N层X印记」的技能 —— 星陨（额外幻伤）、蓄势（每层威力+30%）、
  攻击（每层威力+10%）、萌芽、重组。

### 6. 特性触发样本（roco 的 7 条命名规则，尚未在真实对局验证）
| 特性 | 规则 | 触发条件 |
| --- | --- | --- |
| 专注力 | 物攻技能威力 ×2 | **首回合** |
| 顺风 | 威力 ×1.3 | 速度更快 |
| 破空 | 威力 ×1.3 | 本回合已先于对手行动 |
| 偏振 / 完全偏振 | 受同系伤害减免 | — |
| 绝对秩序 | 受非本系伤害减免 | — |
| 冰钻 | 威力随对手技能总能耗 | 需对手能耗 |

### 7. 我方挨打的一面
现在只有「我方打对手」。守方特性减伤、对手给我方上的印记，只在我方挨打时才有。
- 怎么录：一场里让我方也挨几下，别全程压制。

## 三、建议的录制组合（一次录全很难，分 2–3 份）

1. **第 1 份**：正常 PVP，打满回合别秒退 —— 补「对手技能参数 + 我方挨打」。
2. **第 2 份**：用**印记类技能**的队伍（打湿、疫病吐息、冰点、星陨、蓄势、攻击标记）。
3. **第 3 份**：带**上述 7 个特性**的宠物 + 改天气技能 —— 补特性触发与天气。

**通用注意事项**
- 从**点进对战前几秒**开始录（进战包 `0x1316` 必须录到）；打到出结算再停。
- 中途别切后台（会丢包）。
- 文件名带清楚日期与内容，便于事后对拍。

## 四、录完之后

```bash
# 1) 看这局有什么
go run ./cmd/pcapdump -pcap 你的.pcap

# 2) 抽「技能施放 → 目标 buff 变化」，扩充 buff_id → 印记名 的映射
go run ./cmd/markprobe -pcap 你的.pcap > /tmp/marks.tsv
uv run python scripts/gen_markids.py --from-pcap /tmp/marks.tsv

# 3) 跑一遍服务，看页面拿到的值对不对
go run ./cmd/rocom-capture -pcap 你的.pcap -addr :4940
```
